Markdown → HTML, PDF & docs sites

Your notes, on paper worth reading.

magic-parser turns any Markdown file into a single, self-contained web page or a print-ready PDF, and a folder of them into a docs site. All of it set on grid, lined or dotted paper, in light or dark.

$ npx magic-parser notes.md

No global install. No browser download. Just Node 18+.

A folder in, a docs site out

        
Give it a folder instead of a file and every Markdown file in it becomes a page, with a sidebar that mirrors the folder tree.

      

      
    
        
  • The sidebar collapses, folders open and close, and it remembers where you were from page to page.
    • 
        
  • index.md or README.md becomes each folder's index.html.
    • 
        
  • Links to .md files point at the right pages, #anchors included.
    • 
        
  • Numeric prefixes set the order, and front-matter titles become the labels.
    • 
        
  • Plain static files that work from disk or on any host, such as GitHub Pages.

Configure it your way

      
Settings come from four layers, and each one overrides the one before it. Use the defaults, keep a config file, or pass flags.

    

    

      

        
Defaults

        
Grid paper, cream page, serif type. Nothing to set up.


style: grid
mode:  light

      

      

        
Config file

        
Pass -c, or drop one next to your notes and it's found.


mdp.config.yaml
mdp.config.json
.mdprc

      

      

        
Front matter

        
Per-document overrides under an mdp: key.


mdp:
  page: { style: lined }

      

      

        
CLI flags

        
Override anything for a single build.


-s dotted -m dark
--set page.gridSize=32px

      

    

    
Run magic-parser init to write a config file listing every option, or magic-parser config notes.md to see the final merged result.

  






  

    

      
Command line or library

      
Run it once with npx, add it to a project's scripts, or call it from code. The example docs site covers every option.

    

    

      

        
Terminal


# HTML (default) next to the input
npx magic-parser notes.md

# PDF, dark, dotted, US Letter
npx magic-parser notes.md -f pdf -m dark -s dotted \
  --pdf-format Letter

# Many files into one folder
npx magic-parser docs/*.md -d dist

# A whole folder as a docs site
npx magic-parser docs/ -o public --title "Acme"

# Live preview of a file or a folder
npx magic-parser serve docs/

# Start a config file
npx magic-parser init

      

      

        
Node.js


import { convertFile, renderToHtml, buildSite } from 'magic-parser';

// File → file
await convertFile('notes.md', {
  format: 'pdf',
  config: { page: { style: 'lined' } },
});

// String → full HTML page
const { html } = renderToHtml('# Hello $x^2$', {
  config: { page: { mode: 'dark' } },
});

// Folder → docs site
buildSite('docs', { outDir: 'public' });
